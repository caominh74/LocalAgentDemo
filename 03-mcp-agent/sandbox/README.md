# Demo 3 Sandbox Workspace

This directory serves as the isolated base directory (`cwd`) for all tools (`read`, `write`, `edit`, `bash`, `list_dir`) invoked by the decoupled MCP server in **Demo 3 (`03-mcp-agent`)**.

Drop any files, scripts, or datasets here for testing without affecting repository source files. Paths outside this directory will be rejected by the security guard.
